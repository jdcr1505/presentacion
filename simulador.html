>_ bigdata.lakehouse · simulador · tiempo de venta por código postal

¿En cuánto tiempo se vende una vivienda en tu zona?

Ingresa un código postal de EE. UU. y elige un plazo (o una certeza). El simulador responde con el tiempo típico de venta de la zona y su probabilidad.

Cómo leer el resultado. El modelo estima el tiempo típico de venta de una zona (código postal) para viviendas que se venden. La probabilidad sale de cómo se equivocó el modelo en el pasado, y se muestra en pasos de 5%.

Qué no es. No es una tasación ni una garantía para una propiedad concreta.
